# Building-Manager
Commercial Building Compliance and Records manager

## Compliance HQ Golden Rule

Compliance HQ is a Building Compliance and Records Manager.

### Objective

- Simplicity first.
- Every feature should save the user time.
- The building is always the central record.
- Everything belongs to a building.

### Version 1 Priorities

- Buildings
- Current Tenancy
- Multiple Contacts
- Compliance Timeline
- Documents
- Building History

### Out of Scope (Do Not Build)

- Accounting
- Trust accounts
- Rent collection
- CRM
- Job management
- Maintenance scheduling
- Email systems

### Change Rules

- Every change must be small.
- Never rewrite working code.
- Never change working features unless requested.
- Preserve backwards compatibility.
- Explain changes before implementing.

### Change Report Requirements

For each implementation change, report:

- Files modified
- Functions modified
- Data model changes
- Possible side effects
